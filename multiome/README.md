

#### Contains files for the analysis of joint RNA and ATAC analysis: 10x multiomic



* Part1\_MO(RNA+ATAC)\_merging\_atac.ipynb - merging raw files from different samples to create a unified set of peaks and create a merged Seurat object for ATAC Assay
* Part2\_MO(RNA+ATAC)\_merge\_all.ipynb - merging RNA count matrices and adding ATAC assay to it, some preprocessing steps and links computation 
* Part3\_MO\_DARs\_SNPs\_Motifs\_analysis.ipynb - finding differentially accessible regions(DARs) for cell types, dissection regions and developmental time-points; motif enrichment analysis for cell types; overlapping SNPs from facial-trait associated GWAS for normal variation and disease with various DARs and gene-linked peaks; UMAPs, coverage plots, heatmaps, dotplot visualisations for all parts of the analysis.
